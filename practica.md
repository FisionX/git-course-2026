# Mi primer commit — Día 1

¡Bienvenido/a al taller de Git desde cero! Este archivo usa **Markdown** (`.md`), un formato para escribir texto con títulos, listas y otras marcas sencillas. **No necesitas aprender Markdown todavía:** lo veremos en la próxima sesión. Por hoy, solo completa las respuestas y guarda el archivo.

## Instrucciones

1. Haz un **fork** del repositorio del taller en GitHub.
2. Clona **tu fork** en tu computadora.
3. Abre `practica.md` con un editor de texto y reemplaza los textos entre corchetes por tus respuestas.
4. Guarda el archivo.
5. Comprueba el cambio con `git status`.
6. Prepara el archivo con `git add practica.md`.
7. Crea tu primer commit: `git commit -m "Completo mi practica del dia 1"`.
8. Publica el commit con `git push`.
9. Abre **tu fork** en GitHub y verifica que el archivo se actualizó.

> **Privacidad:** no publiques contraseñas, teléfonos, direcciones, correos privados ni datos sensibles. Puedes usar un apodo.
